# Octagoal Arena — téléchargements

Versions installables du jeu Octagoal Arena (bêta). Les applications vérifient elles-mêmes au démarrage s'il existe une version plus récente et proposent de l'installer.

Dernière version : voir l'onglet **Releases**.

- Windows : `Octagoal-Arena-<version>-Windows.zip`
- Mac (puce Apple M1, M2, M3, M4…) : `Octagoal-Arena-<version>-Mac-Apple-Silicon.zip`
- Mac (processeur Intel) : `Octagoal-Arena-<version>-Mac-Intel.zip`
- Android : `Octagoal-Arena-<version>-Android.apk`
